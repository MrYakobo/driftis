# OBS-streamproblem

## Symptom
- streamen startar inte
- tappade frames
- svart bild i OBS
- ljud ur synk

## Kontroller

1. Verifiera att internetanslutningen är stabil
2. Kontrollera att stream-nyckeln är korrekt
3. Starta om OBS om det inte svarar
4. Kontrollera CPU-användning – stäng onödiga program
5. Verifiera att capture-kortet upptäcks
6. Kontrollera vald ljudingång

## Eskalering
Kontakta livestream-ansvarig om streamen inte kan startas.
