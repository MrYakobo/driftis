# Mixer-routing problem

## Symptom
- vissa kanaler ger inget ljud
- monitormixen är felaktig
- livestream-mixen skiljer sig från salen

## Kontroller

1. Verifiera att rätt scene/snapshot är laddad
2. Kontrollera bus-tilldelningar för berörda kanaler
3. Verifiera aux-send-nivåer för monitorer
4. Kontrollera main LR-tilldelning
5. Bekräfta USB/digital output-routing för livestream

## Eskalering
Kontakta ljudansvarig om routing inte kan lösas.
