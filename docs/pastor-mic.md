# Pastorns mikrofon har inget ljud

## Symptom
- inget ljud i högtalarna
- mätaren rör sig inte på mixern
- livestreamen är tyst

## Kontroller

1. Kontrollera att mikrofonen har batteri
2. Kontrollera att mottagarens ström-LED lyser
3. Bekräfta att kanalen inte är mutad på mixern
4. Verifiera att rätt mixer-scene är laddad
5. Kontrollera kabeln från mottagare till mixer
6. Testa med reservmikrofon

## Eskalering
Kontakta teknikansvarig om problemet kvarstår.
