# Projektorn visar svart bild

## Symptom
- projektorn visar ingen bild
- blå/svart skärm
- meddelande "ingen signal"

## Kontroller

1. Verifiera att projektorn är påslagen
2. Kontrollera HDMI-kabeln i båda ändar
3. Bekräfta att rätt ingångskälla är vald på projektorn
4. Kontrollera datorns skärminställningar (utöka/duplicera)
5. Testa med annan HDMI-kabel
6. Starta om presentationsprogrammet

## Eskalering
Kontakta teknikansvarig om projektorn inte svarar.
