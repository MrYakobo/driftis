# Checklista för gästtalare

## Före ankomst

1. Bekräfta presentationsformat (PowerPoint, PDF, etc.)
2. Förbered reservdator med presentationen laddad
3. Testa mikrofon (handhållen eller mygga)
4. Ställ upp confidence monitor vid behov

## Vid ankomst

1. Testa talarens dator med projektorn
2. Kontrollera ljud från talarens media om tillämpligt
3. Gör soundcheck med talaren
4. Visa talaren confidence monitor och klicker

## Under gudstjänst

1. Ha backup redo att byta till
2. Övervaka ljudnivåer
3. Var redo att hjälpa med slides
