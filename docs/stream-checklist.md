# Checklista för stream

## Före gudstjänst

1. Starta stream-datorn
2. Öppna OBS
3. Verifiera att alla scener är konfigurerade
4. Testa ljudnivåer
5. Starta teststream (privat)
6. Bekräfta video och ljud på övervakningsenhet

## Under gudstjänst

1. Byt scener vid behov
2. Övervaka chatten för problem
3. Håll koll på dropped frames-indikatorn

## Efter gudstjänst

1. Stoppa streamen
2. Spara inspelning om aktiverat
3. Stäng av utrustning
